New 11.7 CLASS-A DEFAULT-VALUE TRAP, six archived instances. The default is
neither null nor 0, so `?? fallback` or `=== 0` short-circuits forever and the
fallback branch never runs. The property chain is complete and the code reads
fine, yet the feature is entirely dead:
  overflowY defaults to 'visible' -> overflow:hidden silently bypasses the BFC
    check in all three places
  getLineHeight() returns 0 -> the fs*1.2 fallback never fires
  borderWidth defaults to a CssRect(0,0,0,0) OBJECT -> `=== 0` is always false,
    so the border shorthand fallback is a dead end (the object variant)
  CssLength::isAuto() returns false -> margin:auto dead
  margin shorthand per-side raw is NULL -> chain present, detection layer broken
  column-gap unset is normal=1em -> needs getRaw() to tell unset from 0
Includes the check to run before writing any `??` or `=== 0`, plus the derived
contract that sentinels must never reach the declaration layer (the lineHeight
-1 sentinel leaked and was read as a number declaration, computing -16px, and
PHP and AOT then diverged on the negative value).

New 11.8 COMPARATOR AND GROUND-TRUTH SELF-BLINDNESS: three cases where the two
sides were not the same source while the report kept printing numbers —

Mandatory rule: verify first-element pxId, depth and counts before trusting any
diff. Plus the CRLF snapshot trap across machines.
