## .html 文件规范

`.html` 文件即浏览器对比的**最终标杆**。必须自包含：

- `<!DOCTYPE html>` + `<meta charset="utf-8">`
- CSS 基线：`html,body { width:1600px; height:800px; font-family:...; font-size:16px; background:#fff; }`
- 锚点：`data-px-anchor="tl"` 和 `data-px-anchor="br"`
- 内容结构与 `.vue` 一致

pipeline 校验失败时终止并报 `[SPEC_FAIL]` / `[VUE_MISMATCH]`。

## 文档维护规范

1. **问题清单 `01-问题清单.md`** 是唯一的权威 Bug 台账。
2. `test_pipeline.php` 每次运行时自动将报告写入 `docs/最新报告.md`（AOT）或 `docs/最新报告-PHP-RT.md`（PHP Runtime），并追写运行历史到 `.run_history.json` 或 `.run_history_php_rt.json`。
3. 所有框架限制**不得跳过**，必须修复至符合 CSS 标准。
4. 每次提交必须检查 `01-问题清单.md` 是否需要更新（新增条目/更新状态/关联 commit）。
