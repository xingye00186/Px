## 文档维护规范

1. **问题清单 `01-问题清单.md`** 是唯一的权威 Bug 台账。`test_log/bug_tracker.md` 和旧 `问题清单.md` 已合并至此。
2. `run.php` 每次运行时自动将报告写入 `02-测试报告/`，旧报告保留。
3. 所有框架限制**不得跳过**，必须修复至符合 CSS 标准。
4. 每次提交必须检查 `01-问题清单.md` 是否需要更新（新增条目/更新状态/关联 commit）。
