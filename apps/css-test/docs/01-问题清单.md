## B-编号问题

### B-001: Auto-height 未排除 absolute 子节点
- 分类: Block
- 文件: framework/Layout/BlockAlgorithm.php
- 状态: 🟡 部分修复（stackBlockChildren 已跳过 absolute，auto-height 含 padding+bottom）
- 描述: CSS2.2 §10.6.3 规定 auto-height 只取 normal flow 子节点的 max-bottom。
- 修复: BlockAlgorithm auto-height 计算时跳过 position=absolute/fixed 子节点

### B-002: Flex 布局 gap 扣除不精确
- 分类: Flex
- 文件: framework/Layout/FlexAlgorithm.php
- 状态: 🟡 待验证
- 描述: flex-grow 分配可用空间时未扣除 gap 导致的系统性宽度偏差
- 修复: §9.5.1 grow 分配前 `available = max(0, containerMain - totalGap)`

### B-003: box-sizing:border-box 未应用于百分比宽度
- 分类: Block
- 文件: framework/Layout/BlockAlgorithm.php
- 状态: 🟢 已修复
- 描述: CSS-UI-3 §4.5: border-box 下百分比 width 包含 padding+border。
- 修复: computeBlockWidth() 在 isPercent() 分支检查 box-sizing

### B-004: Auto-height 未包含最后一个子元素底边距
- 分类: Block
- 文件: framework/Layout/BlockAlgorithm.php
- 状态: 🟢 已修复(@current)
- 描述: CSS 2.2 §10.6.3 规定 auto-height 应包括最后一个正常流子元素的底边距（margin-bottom）。当前 maxBottom 计算只用了 child.y + child.h，未加 margin-bottom。
- 修复: auto-height 循环中为每个子元素增加 margin-bottom 到 bottom 计算
- 效果: case-002 锚点高度从 357→365（目标 366，差 1px），GEOMETRY 从 136→55
