# Px 框架与 Vue 3 模板语义对齐 — 缺失的 CSS/布局特性清单

---
## 二、缺失的 CSS 特性清单（按优先级排序）

### 🔴 高优先级（影响常用布局语义）

| 特性 | Vue 3 典型用法 | Px 当前状态 | 补充方案 |
|------|---------------|-------------|----------|
| **`min-width` / `max-width` / `min-height` / `max-height`** | 限制元素尺寸范围 | 不支持 | 扩展 `LayoutResolver`，在块级/flex 布局中应用约束传递（类似 Flutter 的 BoxConstraints） |
| **`width: auto` / `height: auto`** | 默认值，由内容撑开 | 当前 `0` 表示未指定，需逻辑实现 | 在布局引擎中增加“内容尺寸”计算（文本/子节点尺寸） |
| **`position: relative`** | 相对自身偏移，不影响周围 | 不支持 | 修改 `LayoutResolver`，支持 `top/left` 相对自身位置 |
| **百分比宽度/高度**（如 `width: 50%`） | 相对包含块的百分比 | 不支持 | 布局引擎需在解析时根据父容器实际尺寸计算 |
| **`calc()` 函数** | 动态计算，如 `width: calc(100% - 20px)` | 不支持 | 添加表达式解析和执行（需运行时计算） |
| **`display: inline-block` / `inline`** | 内联或内联块元素 | 不支持（仅 block/flex/grid） | 实现简单内联布局（文本流），但 GDI 绘制文本已支持内联，需支持元素并排 |
| **`vertical-align`** | 行内元素垂直对齐 | 不支持 | 需配合 `inline` 布局实现 |

### 🟡 中优先级（常用但可降级）

| 特性 | Vue 3 典型用法 | Px 当前状态 | 补充方案 |
|------|---------------|-------------|----------|
| **`flex-basis`** | 基础尺寸 | 不支持（仅 `flex` grow） | 扩展 Flex 布局算法 |
| **`flex-shrink`** | 收缩比例 | 不支持 | 同上 |
| **`order`** | 改变子节点顺序 | 不支持 | 排序子节点数组后再布局 |
| **`grid-template-areas`** | 命名区域 | 不支持 | 复杂，可暂缓 |
| **`align-self`** | 单个子项对齐 | 不支持 | 扩展 Flex/Grid 子节点属性 |
| **`justify-self`** | 网格子项对齐 | 不支持 | 同上 |
| **`transform`**（`translate`, `scale`, `rotate`） | 变换 | 仅支持 `translateX/Y`（用于动画） | 添加变换矩阵，影响布局？通常不影响，可单独绘制时应用 |
| **`box-sizing`** | `border-box` / `content-box` | 不支持 | 影响宽高计算，需在 LayoutResolver 中支持 |
| **`clip-path`** | 裁剪 | 不支持 | 通过 GDI 的 `SelectClipRgn` 可支持简单形状 |
| **`cursor`** | 鼠标指针 | 已解析但未使用 | 需在平台层实现 |

### 🟢 低优先级（罕见或可手动替代）

| 特性 | Vue 3 典型用法 | 补充方案 |
|------|---------------|----------|
| **`@keyframes` 动画** | 已支持有限插值 | 完善关键帧插值，支持更多属性 |
| **`transition`** | CSS 过渡 | 已支持部分属性（translate, opacity, 颜色） |
| **`filter`**（模糊、亮度） | 特效 | 需后端支持（GDI 有限，Skia 可支持） |
| **`text-shadow`** | 文字阴影 | GDI 可实现 |
| **`background-image`**（渐变、图片） | 背景图 | 需实现图片加载和绘制 |
| **`linear-gradient`** | 渐变背景 | 当前仅提取首色，需实现真实渐变 |
| **`border-image`** | 边框图片 | 暂缓 |
| **`outline`** | 轮廓 | 类似边框，可支持 |
| **`resize`** | 调整大小 | 桌面窗口通常不支持元素缩放 |

## 三、缺失的语义行为（非 CSS 属性）

| 行为 | Vue 3 语义 | Px 当前 | 补充方案 |
|------|-----------|---------|----------|
| **`v-cloak`** | 未编译模板隐藏 | 不适用（AOT 编译） | 无需 |
| **`v-pre`** | 跳过编译 | 不适用 | 无需 |
| **`v-once`** | 静态内容 | 可通过缓存实现，但不支持指令 | 可后续增加 |
| **`v-memo`** | 缓存子树 | 不适用 | 可选 |
| **`key` 在普通元素** | 用于 diff 提示 | 已支持（`v-for` 及普通节点） | 已实现 type+key 匹配 |
| **`ref`** | 获取 DOM 引用 | 需实现组件/元素引用 | 添加 `ref` 注册机制 |
| **自定义指令** | 扩展行为 | 不支持 | 可后续设计 |
| **`<Teleport>`** | 传送组件 | 不支持 | 可后续 |
| **`<Suspense>`** | 异步组件 | 不支持 | 可后续 |

## 四、推荐实现路线（按阶段）

### 阶段 1（核心布局对齐）
- `min-width`/`max-width`、`min-height`/`max-height`
- `width`/`height: auto`（内容撑开）
- 百分比宽度/高度（简单版本，仅对父容器已知尺寸）
- `position: relative`

### 阶段 2（Flex/Grid 完善）
- `flex-basis`, `flex-shrink`, `order`
- `align-self`, `justify-self`
- `grid-template-areas`（可选）

### 阶段 3（高级 CSS 函数）
- `calc()` 支持（需表达式解析器）
- 更多单位（`em`, `rem`, `vw`, `vh`）→ 需参考根元素或视口

### 阶段 4（视觉增强）
- `transform`（scale/rotate）、`filter`
- `background-image`（图片、渐变）
- `text-shadow`

## 五、与 Flutter 的对比反思

Flutter 布局系统的优势在于**强约束传递**（`BoxConstraints`）和**单次遍历计算**，天然支持 `min/max` 和百分比。Px 的 `LayoutResolver` 目前采用类 CSS 模型，每个模式独立实现，若要支持 `min/max` 和百分比，需要引入约束传递机制（类似 Flutter 但简化）。可考虑在 `LayoutResolver` 中增加一个“约束计算”阶段，再进入具体布局算法。
