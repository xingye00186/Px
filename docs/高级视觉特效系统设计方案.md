# Px 框架高级视觉特效系统设计方案

> 2026-07-31 | 头脑风暴 + 架构设计
> 约束：无 JS / WebGL / Canvas API / Three.js，纯 PHP → AOT → C++/Skia 软件渲染

---

## 一、Px 当前渲染能力基线

| 能力 | 现状 | 等价 Web 技术 |
|---|---|---|
| 渲染后端 | Skia CPU 光栅化 (skia_render.cc) | Canvas 2D |
| 帧驱动 | FrameScheduler 16ms WM_TIMER | requestAnimationFrame |
| 绘制原语 | drawRect / drawText / drawRoundRect / drawImage / clip | ctx.fillRect / fillText / drawImage / clip |
| 颜色 | ARGB 32-bit | rgba() |
| 混合 | Skia SkBlendMode (SrcOver/Screen/Multiply...) | globalCompositeOperation |
| 遮罩 | clipRect / clipRoundRect | ctx.clip() |
| 模糊 | SkMaskFilter::MakeBlur (GDI: GaussianBlur) | filter: blur() |
| 渐变 | SkShader::MakeLinearGradient (未暴露到 PHP) | createLinearGradient |
| 路径 | SkPath (未暴露到 PHP) | Path2D |
| 位图操作 | SkBitmap / SkImage (C++ 层有) | ImageData |

**结论**：Skia 的绘制能力 ≥ Canvas 2D，缺的只是 PHP 层的 API 暴露 + 粒子系统框架。

## 二、架构设计：OverlayEffectLayer（特效覆盖层）

### 核心思想

在 PaintPipeline **UI 树绘制完成后**，追加一个独立的 **EffectLayer** 绘制阶段。特效不参与布局，不生成 VNode/RenderNode，直接向 Skia Surface 发 draw 指令。

```
┌─────────────────────────────────────────────┐
│  Frame N                                     │
│                                              │
│  1. Event Loop (pointer/key/timer)           │
│  2. Reactive Update → VNode Rebuild          │
│  3. Layout (LayoutOrchestrator)              │
│  4. Paint UI Tree (PaintPipeline)            │
│  5. ★ Paint Effect Layer (EffectRenderer) ★  │  ← 新增
│  6. Present (win32: BitBlt / Skia: flush)    │
│                                              │
└─────────────────────────────────────────────┘
```

## 三、特效案例库（20 种场景）

### 🎆 1. 满屏烟花 (Fireworks)

**触发**：收到消息时 / 按钮点击

**算法**：
```
Phase 1 (发射): 
  从底部随机 x 产出 1 个"火箭粒子"
  vy = -800~-1200, vx = 小随机, gravity = 300

Phase 2 (爆炸): 
  当火箭粒子 vy > -100 (接近顶点) → 销毁 → 发射 50-150 粒子
  径向均匀分布，speed = 200-400
  color = 随机亮色 (gold/red/blue/green/purple)
  
Phase 3 (衰减):
  每粒子 gravity = 200, friction = 0.98
  opacity 随 life 线性衰减
  拖尾: 每帧记录前 3 帧位置, 画淡化线段
```

**Skia 绘制**：
- 粒子体: `drawCircle(x, y, 2-4px, color*opacity)`
- 拖尾: `drawLine(prevX, prevY, x, y, color*0.3)`
- 爆炸闪光: `drawCircle(x, y, 20px, white, blendMode=Screen)` 首帧

**性能预估**：500 粒子 × drawCircle = ~0.5ms (Skia CPU)

### 🎊 2. 五彩纸屑 (Confetti)

**触发**：完成任务 / 达成成就

**算法**：
```
从顶部全宽随机发射 200-300 个矩形粒子
每个粒子: 
  size = 4-8px × 8-16px (长条)
  color = 随机饱和色
  rotation = 随机初始角
  rotationSpeed = 随机 ±360°/s
  vy = 100-300 (下落)
  vx = ±50 (飘动)
  airResistance = 0.01 (空气阻力→摆动效果)
```

**Skia 绘制**：
- 每粒子: `save → translate → rotate → drawRect → restore`
- 双面效果: 正面画 colorA, sin(rotation) < 0 时画 colorB (模拟翻转)

---

### 💨 3. 烟雾/雾气 (Smoke)

**触发**：角色释放技能 / 过渡遮罩

**算法**：
```
持续发射器 (底部或指定点):
  每帧发射 5-10 个大圆
  size = 20-60px (比普通粒子大很多)
  opacity = 0.3-0.6
  color = 灰白渐变
  vy = -30~-80 (缓慢上升)
  vx = sin(time) * 10 (轻微摆动)
  life 期间: size 逐渐增大 (1.5x), opacity 逐渐归零
```

**Skia 绘制**：
- 每粒子: `drawCircle + MaskFilter::MakeBlur(sigma=size/3)` → 柔和边缘
- 混合模式: `kMultiply` 或 `kSrcOver` with low opacity
- 高级: 用径向渐变(`LinearGradient`)替代纯色 → 更自然

---

### 🌊 4. 水波纹 (Ripple on Click)

**触发**：每次点击产生一个

**算法**：
```
点击坐标 (cx, cy) 产出 1 个 ring 对象:
  radius: 0 → 150px (300ms)
  strokeWidth: 3px → 0px
  opacity: 1.0 → 0.0
  easing: ease-out
```

**Skia 绘制**：
- `drawCircle(cx, cy, radius, paint)` where paint.style = Stroke
- paint.strokeWidth = lerp(3, 0, t)
- paint.alpha = lerp(255, 0, t)

**变体**：Material Design 的 ink ripple — 用填充圆 + clipRect 限制在按钮区域内

### ❄️ 5. 下雪/下雨 (Snow/Rain)

**触发**：主题/天气背景

**算法**：
```
Snow:
  发射器: 屏幕顶部全宽, emitRate = 30/s
  粒子: size=2-5px, circle/star
  vy = 30-80 (慢), vx = sin(time + offset) * 20 (飘)
  旋转: rotationSpeed = ±60°/s
  生命: 到达底部移除

Rain:
  发射器: 屏幕顶部, emitRate = 100/s
  粒子: 细线 (1px × 10-20px)
  vy = 600-900 (快), vx = 50 (斜)
  无旋转, opacity = 0.6
  拖尾: 画 2px 宽线段
```

### ⚡ 6. 闪电/电弧 (Lightning)

**触发**：错误提示 / 充电动画

**算法**：
```
Fractal Lightning:
  起点 (x1, y1), 终点 (x2, y2)
  中间插入 N 个节点 (N=5-10)
  每个节点: x += random(-30, 30), y = lerp(y1, y2, i/N)
  分支: 每个节点 20% 概率产出一条短分支
  
闪烁:
  Frame 0: 全亮 (opacity=1)
  Frame 1-3: 快速衰减 (0.8→0.3→0)
  可重复 2-3 次 (模拟多次放电)
```

**Skia 绘制**：
- `drawPath` 连接所有节点
- paint: strokeWidth=2-3, color=white/cyan, blendMode=Screen
- 光晕: 同路径再画一遍, strokeWidth=8, blur=4, opacity=0.5

### 🌟 7. 星星爆发 (Star Burst)

**触发**：获得积分 / 收藏

**算法**：
```
从目标元素中心发射 12-20 个星形粒子
  speed = 200-400, 均匀角度分布
  size = 8-12px
  rotation = 随机
  life = 0.5s
  gravity = 100 (轻微下坠)
  color = gold → white (颜色过渡)
  scale: 1.0 → 0.0 (收缩消失)
```

### 🔥 8. 火焰 (Fire)

**触发**：持续特效背景

**算法**：
```
底部发射器 (宽度=目标宽度):
  emitRate = 80/s
  粒子 size = 10-30px (大圆)
  vy = -150~-300 (上升)
  vx = random(-20, 20)
  life = 0.4-0.8s
  
颜色: 根据 life/maxLife 插值
  0%: 白/黄 (0xFFFFFF00)
  30%: 橙 (0xFFFF6600)
  60%: 红 (0xFFFF0000)
  100%: 黑/透明 (0x00000000)
  
size: 随 life 增大 (1x → 2x)
```

**Skia 绘制**：
- 每粒子: blurred circle + blendMode=Screen → 叠加发光
- 底部白光: 一个大的半透明白色椭圆

---

### 💫 9. 轨迹跟随 (Trail Follow)

**触发**：鼠标移动轨迹 / 导航动画

**算法**：
```
记录最近 20 帧的鼠标坐标
每帧从最新坐标发射 3-5 个小粒子:
  speed = 10-30 (微小扩散)
  size = 2-4px
  life = 0.3s
  color = 主题色

轨迹线:
  连接 20 帧坐标画 polyline
  strokeWidth 从新到旧: 3px → 0px
  opacity 从新到旧: 1.0 → 0.0
```

### 🌈 10. 彩虹光环 (Rainbow Halo)

**触发**：VIP/特殊状态

**算法**：
```
绕目标元素的环形路径:
  N = 6 色块 (红橙黄绿蓝紫)
  每色块: arc 60°
  整体旋转: rotation += 90°/s
  
内发光:
  向内 feather 10px 的径向渐变
  从边缘色 → 透明
```

**Skia 绘制**：
- 6 次 `drawArc` + blendMode=Screen
- 外层: blur=8 的同色弧 (光晕)

### 📱 11. 通知弹入 (Notification Slide + Bounce)

**触发**：新消息到来

**算法**：
```
Phase 1 (滑入):
  translateY: -80px → 0 (150ms, ease-out)
  opacity: 0 → 1
  scale: 0.8 → 1.0

Phase 2 (弹跳):
  translateY: 0 → -5px → 0 (100ms, spring)

Phase 3 (停留 3s)

Phase 4 (滑出):
  translateY: 0 → -80px (200ms, ease-in)
  opacity: 1 → 0
```

这个可以直接用现有 AnimationManager + addTransition 实现,不需要粒子系统。

### 🎭 12. 页面转场 (Page Transition Wipe)

### 🕸️ 18. 粒子网格连线 (Particle Network)

**触发**：科技感背景

**算法**：
```
屏幕随机分布 50-80 个粒子
每粒子缓慢随机漂移 (vx/vy = ±10-30)
```

## 四、框架架构预设条件

### 必须新增的基础设施

| 组件 | 作用 | 实现难度 | 依赖 |
|---|---|---|---|
| **EffectRenderer** | 在 paint 之后执行特效绘制 | 低 | PaintPipeline 扩展 |
| **ParticleSystem** | 粒子生命周期 + 物理更新 | 中 | 无 |
| **C++ Draw API 暴露** | circle/line/path/blur/gradient/blendMode | 中 | skia_render.cc |
| **随机数生成器** | 确定性随机(seed)+ 快速随机 | 低 | 无 |
| **对象池** | 粒子复用避免 GC 压力 | 低 | 无 |
| **空间索引** (可选) | 粒子网格连线的 O(n) 查询 | 中 | 无 |

## 五、性能预算

| 场景 | 粒子数 | Draw calls/帧 | 预估耗时(Skia CPU) | 帧率影响 |
|---|---|---|---|---|
| 单次烟花爆发 | 100-150 | 150 | ~1ms | 无 |
| 满屏烟花(5发) | 500-750 | 750 | ~3ms | 轻微(仍>50fps) |
| 持续下雪 | 200 | 200 | ~1ms | 无 |
| 粒子网格(80点) | 80+连线 | ~400 | ~2ms | 轻微 |
| 火焰(持续) | 300 | 300 | ~2ms | 轻微 |

**关键优化**：
1. **对象池复用**：粒子死亡后回收到池中,emit 时取出而非 new
2. **批量 drawCircle**：C++ 层合并相同 paint 参数的 draw calls
3. **脏区域**：只重绘有活跃粒子的屏幕区域(如果 Skia 支持)
4. **降采样**：特效层可用 0.5x 分辨率渲染再放大(模糊效果反而更好)

## 六、与现有系统的集成点

| 系统 | 集成方式 |
|---|---|
| **FrameScheduler** | 有活跃 Effect 时保持帧驱动(不 sleep) |
| **AnimationManager** | 共享 tick 时钟；简单动画仍走 AM，粒子走 EffectRenderer |
| **PaintPipeline** | paint() 末尾调 EffectRenderer::paint() |
| **hitTest** | 特效层不参与 hitTest(纯装饰) |
| **RenderTreeManager** | 无交互——EffectRenderer 完全独立 |
| **AOT** | 粒子参数用数组常量(非闭包)；Preset 类的所有配置是 const |

## 八、与浏览器方案的对比

| 特效 | 浏览器实现 | Px 实现 | Px 优势 |
|---|---|---|---|
| 粒子系统 | Canvas 2D + rAF | EffectRenderer + Skia | 无 GC 暂停；类型化(AOT 静态分配) |
| 3D 效果 | WebGL/Three.js | ❌ 不支持 | — |
| 模糊/辉光 | CSS filter / SVG filter | Skia MaskFilter | 实时可控(每粒子不同 sigma) |
| 路径动画 | SVG animate / CSS motion-path | SkPath + 手动插值 | 更精确控制 |
| 视频/Lottie | video / lottie-web | ❌ 不支持(可通过 SkiaSharp 帧解码) | — |
| 物理模拟 | Matter.js / cannon.js | 内联物理(重力+摩擦+碰撞) | 零依赖；AOT 编译后性能好 |

**Px 不能做的(诚实)**：
- 真 3D(旋转、透视投影)——除非用软件 3D 渲染(性能差)
- 视频播放——需要解码器(可未来通过 FFmpeg 集成)
- 着色器程序(GLSL/WGSL)——Skia CPU 不支持自定义 shader

**但 Px 做 2D 粒子特效完全够用**——Skia 的 2D 能力不弱于 Canvas。
