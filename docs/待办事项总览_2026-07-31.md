## 核心判断（不可协商）

1. **Reactive Array 修复是一切前置** — 不修这个，所有 array 状态应用在 exe 中都不能用
2. **Slot 是组件库刚需** — 没有 Slot，vc-ui 60 个组件只是摆设
3. **性能优化等 Slot 和 Widget 稳定后再做** — 先正确再快速
4. **跨平台是远期** — 桌面端还没做好不要分心
5. **CLI ≡ AOT** — 任何功能都必须双模式验证
